# KingCountyWA_HouseSales_TableauDashboard
Interactive Tableau dashboard analyzing 21,060 home sales in King County, Washington (May 2014 to May 2015) across 70 zip codes. Includes a price map, sales calendar, and histograms of price, bedrooms, and bathrooms, with click-to-filter actions and sliders for living area, lot size, and year built. Built following a guided tutorial.
